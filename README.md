<h1> Nekaur Aur Helper </h1>

> **Project Status:** Under development.

> **Core Concept:** This AUR helper uses a declarative system for package management and configuration.

>**config example:**

<code>
aur_package {
 "package": "version"
}
</code>

>**Ctl command example:**

<code>
nekaur [ags] [flag]
</code>
